Gramática TramaDSL v2

program       → statement*
statement     → DEF IDENTIFICADOR = expression ;
              | IDENTIFICADOR = expression ;
              | command expression ;
              | SI ( expression ) ENTONCES { statement* } (SINO { statement* })?
command       → INICIAR_TURNO | REGISTRAR | REPORTAR_MERMA
              | DETENER_MAQUINA | EMITIR | CAMBIAR_LOTE
expression    → comparison ((+ | -) comparison)*
comparison    → term ((== | != | < | > | <= | >=) term)?
term          → factor ((* | /) factor)*
factor        → NUMERO | CADENA | IDENTIFICADOR | (expression)
